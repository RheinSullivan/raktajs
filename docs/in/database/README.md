# Ekosistem Database Rakta.js

Rakta.js mendukung berbagai mesin database relasional, document-store, in-memory, dan serverless.

## Mesin Database Resmi
- [SawitDB Engine](/id/database/sawitdb.md) - Single-file database engine buatan WowoEngine.

## Relasional & Enterprise
- [Oracle Database](/id/database/oracle.md) - RDBMS enterprise untuk transaksi dan skenario berbeban tinggi.
- [PostgreSQL](/id/database/postgresql.md) - Database relasional yang paling direkomendasikan.
- [MySQL](/id/database/mysql.md) - Database relasional populer dengan dukungan hosting sangat luas.
- [SQLite](/id/database/sqlite.md) - Database SQL tersemat tanpa server tambahan.
- [MariaDB](/id/database/mariadb.md) - Fork MySQL berkinerja tinggi.

## Document & In-Memory
- [MongoDB](/id/database/mongodb.md) - Database dokumen NoSQL fleksibel.
- [Firebase](/id/database/firebase.md) - Database real-time cloud dari Google.
- [Redis](/id/database/redis.md) - In-memory data store untuk caching dan session.

## Serverless & Edge Databases
- [PlanetScale](/id/database/planetscale.md) - Serverless MySQL dengan schema branching.
- [Neon](/id/database/neon.md) - Serverless PostgreSQL dengan komputasi dan penyimpanan terpisah.
- [Turso](/id/database/turso.md) - Serverless SQLite terdistribusi berbasis libSQL.
