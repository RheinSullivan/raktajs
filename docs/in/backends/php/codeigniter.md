# Integrasi Backend CodeIgniter 4

CodeIgniter 4 adalah framework PHP ringan dan cepat dengan footprint minimal.

## Fitur Utama
- **Arsitektur**: MVC dengan eksekusi sangat efisien dan footprint memori kecil.
- **Bahasa**: PHP 8.x.
- **Kompatibilitas Rakta.js**: RESTful API Controller dan SawitDB library integration.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=codeigniter
```

## Database Yang Didukung
- SawitDB (`wowoengine/sawitdb-php`), MySQL, PostgreSQL, SQLite, Oracle Database.
