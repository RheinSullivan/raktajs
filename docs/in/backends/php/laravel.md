# Integrasi Backend Laravel

Laravel adalah framework PHP modern yang paling populer dengan ekosistem sangat kaya.

## Fitur Utama
- **Arsitektur**: MVC dengan Eloquent ORM, Artisan CLI, dan Service Providers.
- **Bahasa**: PHP 8.x.
- **Kompatibilitas Rakta.js**: Integrasi API endpoints, CSRF middleware, dan SawitDB PHP adapter (`wowoengine/sawitdb-php`).

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=laravel
```

## Database Yang Didukung
- SawitDB (`wowoengine/sawitdb-php`), PostgreSQL, MySQL, SQLite, Oracle Database.
