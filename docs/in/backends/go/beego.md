# Integrasi Backend Beego

Beego v2 (github.com/beego/beego) adalah framework enterprise MVC berbasis Go (Golang).

## Fitur Utama
- **Arsitektur**: Full-stack MVC dengan Beego ORM, Session, dan Bee CLI tool.
- **Bahasa**: Go 1.22+.
- **Kompatibilitas Rakta.js**: Generasi starter backend MVC terstruktur.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=beego
```

## Database Yang Didukung
- PostgreSQL, MySQL, SQLite, Oracle Database.
