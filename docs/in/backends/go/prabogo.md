# Integrasi Backend Prabogo

Prabogo adalah framework backend berbasis Go (Golang) berkinerja tinggi.

## Fitur Utama
- **Arsitektur**: High-performance HTTP router dengan kompilasi biner mandiri.
- **Bahasa**: Go 1.22+.
- **Kompatibilitas Rakta.js**: Generasi starter backend Go terintegrasi dengan Rakta.js.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=prabogo
```

## Database Yang Didukung
- PostgreSQL, MySQL, SQLite, SawitDB, Oracle Database.
