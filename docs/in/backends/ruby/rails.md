# Integrasi Backend Ruby on Rails

Ruby on Rails adalah framework web MVC legendaris berbasis Ruby.

## Fitur Utama
- **Arsitektur**: MVC dengan Active Record ORM dan Convention over Configuration.
- **Bahasa**: Ruby 3.x.
- **Kompatibilitas Rakta.js**: Integrasi API Mode.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=rails
```

## Database Yang Didukung
- PostgreSQL, MySQL, SQLite, Oracle Database.
