# Integrasi Backend Hanami 2.x

Hanami 2.x adalah framework web modern Ruby yang mengutamakan kecepatan, konsumsi memori rendah, dan arsitektur modular.

## Fitur Utama
- **Arsitektur**: Component-based architecture dengan ROM (Ruby Object Mapper).
- **Bahasa**: Ruby 3.x.
- **Kompatibilitas Rakta.js**: Generasi starter backend Ruby berkinerja tinggi.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=hanami
```

## Database Yang Didukung
- PostgreSQL, MySQL, SQLite.
