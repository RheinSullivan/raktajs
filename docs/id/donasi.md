# Donasi & Transparansi Keuangan

## Tentang Donasi

Rakta.js menerima donasi publik untuk dua tujuan:

1. **Pemeliharaan Infrastruktur Rakta.js**: Server, domain, SSL, CDN, package registry, security monitoring
2. **Bantuan Kemanusiaan**: Palestina, kaum dhuafa, panti asuhan, panti jompo, korban bencana

**Link Donasi Resmi:**
- https://buymeacoffee.com/rheinsullivan

**Pengelola:**
- Rhein Sullivan (Muhammad Rizky Ramadhan) - Lead Maintainer Rakta.js

---

## Komitmen Transparansi 100%

Setiap rupiah yang masuk akan dilaporkan secara publik. Tidak ada pengurangan selain untuk kebutuhan yang tercatat di bawah ini.

### Pembagian Dana

**Biaya Operasional Framework (Maksimal 30%):**
- Server hosting & bandwidth
- Domain & SSL certificate  
- CDN & package registry fees
- Security monitoring tools
- Development tools & services
- Emergency infrastructure repairs

**Bantuan Kemanusiaan (Minimal 70%):**
- Bantuan untuk Palestina 🇵🇸
- Bantuan untuk kaum dhuafa & keluarga kurang mampu
- Panti asuhan & anak yatim
- Panti jompo & lansia
- Korban bencana alam
- Bantuan darurat kemanusiaan

### Prinsip Transparansi

- Laporan keuangan dipublikasi setiap bulan di repository
- Bukti transfer & distribusi akan di-upload sebagai dokumentasi
- Tidak ada pemotongan untuk kepentingan pribadi
- Audit publik dapat dilakukan kapan saja oleh siapa saja

## Mitra Distribusi Bantuan

Lembaga resmi yang ingin menjadi mitra penyalur dana bantuan kemanusiaan dapat mendaftar dengan syarat:

### Persyaratan Lembaga

1. **Status Legal Jelas:**
   - Yayasan terdaftar
   - NGO/LSM resmi
   - Panti asuhan/jompo berizin
   - Lembaga zakat/infaq/sedekah resmi

2. **Transparansi & Akuntabilitas:**
   - Bersedia membuat laporan distribusi
   - Menyediakan bukti penyaluran (foto/dokumen)
   - Membuka akses audit jika diperlukan

3. **Program Aktif:**
   - Program untuk kaum dhuafa/yatim/lansia/Palestina
   - Penyaluran makanan/sembako/bantuan langsung
   - Bantuan medis/pendidikan/tempat tinggal

### Cara Mendaftar

1. **Buka Issue di GitHub**
   - Repository: https://github.com/RheinSullivan/raktajs
   - Title: `[Mitra Distribusi] Nama Organisasi Anda`

2. **Lampirkan Dokumen:**
   ```
   Nama Organisasi: [Nama]
   Status Legal: [Yayasan/NGO/Panti/dll]
   Nomor Registrasi: [Nomor]
   Alamat Lengkap: [Alamat]
   Kontak Resmi: [Telepon/Email/Website]
   
   Program Bantuan:
   - [Deskripsi program 1]
   - [Deskripsi program 2]
   - [dll]
   
   Proposal Distribusi:
   [Jelaskan bagaimana dana akan disalurkan, kepada siapa, berapa orang, dll]
   
   Lampiran:
   - [Link/foto akta pendirian]
   - [Link/foto NPWP lembaga]
   - [Link/foto izin operasional]
   - [Link profil lembaga/website]
   ```

3. **Proses Review:**
   - Tim maintainer akan review dokumen
   - Verifikasi legalitas dan kredibilitas
   - Koordinasi metode transfer & pelaporan
   - Pengumuman kemitraan secara publik

4. **Penyaluran Dana:**
   - Transfer sesuai kesepakatan
   - Bukti transfer dipublikasi
   - Lembaga memberikan laporan distribusi
   - Foto/dokumentasi penyaluran di-upload

## Verifikasi & Audit Donasi

### Cara Cek Laporan Keuangan

1. **Via Repository:**
   - Buka folder `/docs/financial-reports/[tahun]/`
   - Lihat file `[bulan].md` untuk laporan bulanan

2. **Via GitHub Issues:**
   - Cari label `financial-report`
   - Setiap laporan bulanan akan di-posting sebagai Issue

3. **Via README:**
   - Bagian "Support & Humanitarian Donations" akan di-update dengan summary

### Mengajukan Pertanyaan

Jika Anda punya pertanyaan tentang donasi atau ingin melakukan audit:

1. Buka Issue di GitHub dengan title: `[Pertanyaan Donasi] Topik Anda`
2. Semua pertanyaan akan dijawab secara publik
3. Tidak ada yang disembunyikan

### Prinsip Kami

- **Transparansi Mutlak**: Semua data keuangan terbuka
- **Akuntabilitas Penuh**: Setiap rupiah dapat dipertanggungjawabkan
- **Audit Terbuka**: Siapa saja boleh melakukan audit
- **Tidak Ada yang Disembunyikan**: Semua bukti tersedia
