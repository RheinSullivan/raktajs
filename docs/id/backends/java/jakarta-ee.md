# Integrasi Backend Jakarta EE 10 / J2EE

Jakarta EE 10 (dahulu J2EE) adalah standar industri enterprise Java untuk aplikasi skala besar.

## Fitur Utama
- **Arsitektur**: Standardized enterprise specifications (Jakarta RESTful Web Services / JAX-RS, Jakarta Persistence / JPA, CDI).
- **Bahasa**: Java 17+.
- **Kompatibilitas Rakta.js**: Generasi starter backend Jakarta EE 10.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=jakarta-ee
```

## Database Yang Didukung
- PostgreSQL, MySQL, Oracle Database.
