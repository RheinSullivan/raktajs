# Integrasi Backend Spring Boot 3.x

Spring Boot 3.x adalah framework Java enterprise berkinerja tinggi.

## Fitur Utama
- **Arsitektur**: Production-ready enterprise framework dengan Spring Web, Spring Data JPA, dan embedded Tomcat.
- **Bahasa**: Java 17+.
- **Kompatibilitas Rakta.js**: Integrasi RESTful API terpadu.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=spring-boot
```

## Database Yang Didukung
- PostgreSQL, MySQL, Oracle Database, H2, SQLite.
