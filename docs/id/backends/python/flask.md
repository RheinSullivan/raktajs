# Integrasi Backend Flask

Flask 3.x adalah WSGI microframework Python yang fleksibel dan efisien.

## Fitur Utama
- **Arsitektur**: Microframework minimalis dengan routing fleksibel.
- **Bahasa**: Python 3.x.
- **Kompatibilitas Rakta.js**: CORS integration, JSON response standardization.

## Penggunaan CLI
```bash
bun create rakta my-app --fullstack --backend=flask
```

## Database Yang Didukung
- PostgreSQL, MySQL, SQLite, SawitDB, Oracle Database.
